# Careloop logo

The user supplied the heart, infinity ribbons, and sprout artwork. The built-in imagegen tool prepared a transparent version; this is the source in [assets/careloop-logo-source.png](../assets/careloop-logo-source.png). The original supplied JPEG was left unchanged.

The website uses a 256 px WebP derivative, `static/careloop-logo.webp`. The favicon and installed-app icons use 192 px and 512 px PNG derivatives with a light background and padding for device masks. Derivatives were sized and encoded with browser canvas. Header artwork is about 15 KB.

## Image preparation prompt

Use case: background-extraction. Edit target: attached existing Careloop logo. Prepare the supplied logo as a transparent app brand asset. Preserve EXACT artwork identity: same interlocking coral heart, blue and teal infinity ribbons, green arc and sprout, same relative geometry, shapes, gradient colors, overlaps and smooth edges. Remove only the ivory background including enclosed negative spaces; no redesign, no text, no extra elements. Center full intact logo on square transparent canvas with a small consistent 8% transparent margin. Genuine alpha transparency. Output clean high quality logo for website header and phone app icon.
